# Datos – Metal Tech

> **Declaración:** todos los datos de este proyecto son **sintéticos**, generados por simulación a partir de `configs/assets.yaml` y `configs/failure_modes.yaml`. No provienen de una planta real ni contienen datos personales. Los técnicos y turnos son ficticios.

La ficha de datos completa (supuestos del simulador, variables, distribución de clases, sesgos y limitaciones) se escribe en la **Fase 3**, junto con el generador (`python -m metaltech.data.generator`). Los archivos generados van a `data/synthetic/` y no se versionan.
